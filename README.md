# 局域网快传 v3.6

电脑（浏览器扩展）↔ 手机（Android App）在同一局域网内互传文本、图片与任意格式文件。

## 本次更新（v3.6）

三端版本号已统一：中继 `v3.6`／扩展 `3.6.0`／安卓 `3.6`（versionCode 14）。

**变更**

1. **浏览器端：文件选择器不再卡住**
   - 原先点发送会开一个小窗口，并在其中调用 `input.click()`。但 `chrome.windows.create`
     打开的新窗口**不继承用户手势**，浏览器会静默忽略这次点击，界面就永远停在
     "正在打开文件选择器"。
   - 现改为在面板内直接放 `<input type=file>`，由按钮点击直接触发：手势完整、少一层界面，
     选完立即读取并交给后台发送（后台是持久 Service Worker，即便面板随后关闭也能发完）。
   - 已删除不再需要的 `picker.html` / `picker.js` / `picker.css`。

2. **浏览器端：批量消息合并不再依赖相邻**
   - 此前只有**连续**的同批消息才会聚合，这批消息之间一旦插入其他消息就会散成多个气泡。
   - 现按 `batchId` 全局归并，并按 `batchIndex` 还原发送顺序。

3. **下载改为右键触发**
   - 单击图片是看大图，单击文件不再落盘；保存统一走右键菜单（`contextmenu`），避免误触。

4. **安卓端：批量气泡收紧**
   - 只有两项以上才折叠；单张图/单个文件按普通消息渲染，不再套一个空壳气泡。
   - 折叠态固定为「两个完整 + 第三格半宽」，角标含义改为"还有几项未露出"。
   - 新增紧凑气泡背景 `bg_bubble_batch_*`（内边距 12/8dp → 5dp），
     网格尺寸与气泡 `maxWidth` 重新配平（展开三列 266dp < 280dp）。

**校验**

- 扩展端 JS：`node --check` 全部通过。
- 资源引用扫描：0 处缺失；XML 全部解析通过。
- 跨文件符号扫描：0 处待核实引用。
- 中继端到端测试：10 项全部通过。

## 版本记录

### v3.9（当前）
- **自动下载改为只认「系统分享」来源**：去掉「图片自动下载」开关。
  手机端经系统分享发出的图片 / 文件带 `source:"share"` 标记，接收端自动落盘；
  应用内主动发送的消息保持安静，由用户手动下载。
- **下载动作收进选项框**：电脑扩展端右键、手机浏览器长按、安卓端长按，
  弹出同一组选项，菜单内含「下载」。单击图片只看大图，单击文件不再落盘。
- **去掉批次号分组**：发送端不再写 batchId。接收端自动识别
  「连续 + 相邻 ≤20 秒 + 同为图片 + 同一方向 / 设备」的若干消息，折成一组。
- **图片组新样式**：组内图片自上而下依次排列、不带任何消息气泡边框；
  折叠时露出前两张完整图 + 第三张上半截（共 2.5 张），
  结尾一个半透明「展开其余 N 张 / 收起」按钮。
- 安卓端：适配上述协议与版式，分享入口支持任意格式文件（不再只收图片）。

### v3.8
- **修复 APK 编译失败：`Unresolved reference: BuildConfig`**
  项目使用 AGP 8.1.4，而自 AGP 8.0 起 `buildConfig` 特性默认关闭，
  导致 `WebSocketManager.kt` 中引用的 `BuildConfig` 类未生成。
  已在 `buildFeatures` 中显式开启 `buildConfig = true`。
- 版本号三端统一：中继 `v3.8`／扩展 `3.8.0`／安卓 `3.8`（versionCode 16）。

### v3.7
- **修复「提示未连接、文件却传过去了」**：`sendRaw` 未连上时本会入队待发，
  却返回 false，界面据此误弹「未连接」。现入队成功即视为受理（仅用户主动断开才拒绝）。
- **修复「多文件只显示一个」**：此前多个文件也带 batchId，被渲染层当作一组、
  非首条整条隐藏。现**只有多张图片才合成一组**，多个文件各自独立成泡。
- **电脑端图片显示不出来**：原图 base64 常达数 MB，超长 data URL 赋给 `img.src`
  在扩展页面里解码失败（只剩提示文字）。改为 **data URL → Blob → objectURL** 渲染。
- **批次改为纵向堆叠 + 半透明展开按钮**：折叠露前 2 项，底部渐变遮罩与「▽ 展开其余 N 项」，
  展开向下铺开全部并变「△ 收起」；项数不超过 2 时按钮自动隐藏。
- 安卓端同步：图片组纵向堆叠、气泡更紧凑、展开按钮改为半透明胶囊。
